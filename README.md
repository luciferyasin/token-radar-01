A token launch radar dashboard that ranks pre-token protocols by implied value derived from DeFiLlama snapshot data: 200 rows, a value model built from the snapshot's own TVL and 7-day change, concrete farm plans, and a sortable, filterable dashboard with per-protocol detail views.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
